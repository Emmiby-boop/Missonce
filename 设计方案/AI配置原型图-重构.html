AI 配置页（重构版）— 设计规范说明

重构要点（对照优化方案）

问题重构方案
状态指示器重复状态仅在顶部「状态总览」+ Key 列表项显示，Tab 标签只保留小圆点，不重复文字状态
白名单保存逻辑混乱白名单 Tab 内用子分段（分类 / 标签）拆分，各自独立保存按钮 + 一键保存全部
触控目标过小Tab 标签、segment 分段项高度提升，点击热区≥44pt
弹窗滚动不可靠Key 添加/编辑弹窗统一 scroll-view + sheet overflow:hidden
缺少错误状态新增全局 error-state + 重试按钮
无 AI 识别设置视觉模型卡新增「AI 识别设置」块：自动识别 / 自动应用开关

功能清单

Tab核心功能
视觉模型厂商/模型/地址/Key/提示词 · AI 识别设置 · 测试+保存
文案模型启用开关 · 厂商/模型/Key/提示词 · 测试+保存
API Key列表 · 复制/编辑/删除 · 添加弹窗(scroll-view)
语录AI 批量生成预览 · 手动添加 · 删除
白名单子分段 分类/标签 · 标签预览 · 独立保存

设计规范遵循

规范实现
主色#07C160
字体系统字体（设计系统强制，不加载自定义字体）
图标Feather 线性 SVG，stroke-width 2
弹窗底部 Sheet，max-height 90%，scroll-view
四态loading / empty / error / success
