## 五、GIF 性能优化方案

### 5.1 问题

微信小程序 `<image>` 组件不支持程序化暂停 GIF，滚动时全部播放会：
- 耗流量（尤其是 4G 用户）
- 耗内存（低端机卡顿）

### 5.2 解决方案

**方案 A**（推荐，纯前端）：
```javascript
// 用 IntersectionObserver 监听可视状态
// 滚出时用静态封面图替换 GIF URL，滚入时恢复

onLoad() {
  this._observeGifs()
},

_observeGifs() {
  // 对瀑布流里的每个 GIF 卡片创建观察器
  const observer = wx.createIntersectionObserver(this)
  observer.relativeToViewport({ threshold: 0 }).observe(
    '.waterfall-item',  // 卡片选择器
    (res) => {
      if (!res.intersectionRatio) {
        // 滚出可视区：用静态封面替换
        this._replaceGifWithStatic(res.dataset.id)
      } else {
        // 滚入可视区：恢复 GIF
        this._restoreGif(res.dataset.id)
      }
    }
  )
}
```

**方案 B**（简单但体验稍差）：
- 只在预览页播放 GIF
- 列表里全部用静态封面图（`?imageMogr2/thumbnail/...` 第一帧）

> 建议：先用方案 B 快速上线，后续迭代再加入方案 A
