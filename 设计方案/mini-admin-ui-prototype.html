设计决策

决策原因
移除审核流所有资源由管理员直接控制状态，简化为 CRUD + 状态切换
广告配置入内容 Tab广告与页面内容强关联，放在内容管理下更直观
首页 Tab 独立管理小程序核心入口配置，需单独模块管理
SVG 图标统一Feather Icons 风格线性 SVG，与微信原生设计一致
全宽无边框卡片最大化内容区域，沉浸式阅读体验
Missonce Admin Mini Program — 独立管理后台小程序
技术栈: 微信原生小程序 + 云开发 | 云环境: missonce-99 | 复用 ~17 个现有云函数
设计风格: 清晰运营 — #07C160 主色调 · 全宽卡片 · SVG 线性图标 · 深色模式适配
