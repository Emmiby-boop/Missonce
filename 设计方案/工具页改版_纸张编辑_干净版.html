删掉的

顶部「工具箱」大标题、XIAOLAJIAO · TOOLS kicker、04 tools / daily 元信息行、 STREAK / DAY 04 / 07 / BALANCE 等英文小标签、工具数量角标、 底部 v2 · 2026 版本行、朱砂印章、作品横滚带、卡片与阴影。

保留的

1px 细线分隔的列表、超大等宽数字、右侧小箭头悬停位移、size 带来的行型差异、 图标方块（color 字段，中性底 + 彩色线，不铺色块）。

页面只剩三件事

从上到下：签到（46px 等宽数字 + 1px 进度线 + 细线按钮）→ 创作工具（细线列表）→ 我的辣度值（一行）。 没有标题栏大标题，没有英文标识，没有装饰角标。视觉锚点只有三个：签到数字、绿短标、辣度值金额。

为什么还是「高级」而不是「寡淡」

卡片网格是容器思维——每个东西装进一个盒子，盒子一多就变成模板。 这一版是版面思维：用 1px 细线切分信息层级，用字号（46px 数字 → 16px 标题 → 11px 描述） 建立视线顺序，用留白代替边框。东西少了，但每一处的重量都不一样，眼睛知道先看哪里。

后台配置怎么保留

现有后台（工具箱管理）可配 title / desc / icon / linkType / linkUrl / size / color / visible / sort， 这一版全部字段都还有意义，不需要改数据结构：

落地要点

  • 不出现英文标识：STREAK / DAY 04 / 07 / BALANCE / 版本号全部删掉， 页面内不再有拉丁文装饰。这四行文字删掉后，页面少了 4 个"设计感表演"，反而更像正经工具。
  • wide 短标用伪元素：.row.wide::before 定位在行左、height: calc(100% - 32px)。 这样即使后台把所有项都设成 wide，左侧也是 4 个独立短标，不会连成一根长绿线（实测对比过：连成一条时很脏）。
  • 单位换算：原型 390px 宽，小程序 1px ≈ 2rpx。签到数字 46px → 92rpx； 细线务必写 1rpx 而非 1px，否则高分屏上会变粗、纸张质感全毁。
  • 字体：全站统一系统无衬线，不需要加载任何中文字体。只有数字部分建议 wx.loadFontFace 加载 IBM Plex Mono（拉丁数字子集约 20KB）——小程序不支持 font-variant-numeric，不加载的话签到数字在不同机型上宽度会跳。加载失败兜底系统字体， 视觉不会崩，只是数字不再严格对齐。
  • 想加编辑感再说：若之后觉得太素，只给 wide 行标题加 font-family:"Noto Serif SC",serif 即可 （iOS 可退 Songti SC，Android 加载思源宋体 woff2 子集）。这一版的骨架是排版和留白， 不是字体，加不加都成立。
  • 导航栏：原型里导航栏留空（44px）。小程序落地时可以保留系统标题「工具箱」， 也可以在 tools.json 里设 "navigationBarTitleText": "" 留白——两种都不影响下方布局。
  • 点击区域：square 行实际高度 54px（108rpx），wide 行 72px（144rpx），均超过 44px 最小触达标准，无需额外 padding。
  • 作品带：这一版按「干净」的要求删掉了。如果之后想在工具页露出精选头像/壁纸， 建议加在工具列表之上、签到区之下，用一条 88px 高的横向 scroll-view， 左右出血到屏幕边缘——它是最容易加回来、也最容易再加出彩的部分。
  • 风险：直角 + 零阴影在浅色下成立，但如果以后整站切深色，#eef0f2 的细线在深色底上会偏亮， 需要单独定义一套深色线色（建议 rgba(255,255,255,.10)）。

建议直接按这一版开工。它跟首页、专题页、我的页用的是同一套灰阶和同一个绿， 切 tab 时不会有割裂感；同时后台四个配置字段一个没丢，你随时能在后台把某项从「方形」改成「宽形」看效果。

关于「和站内保持一致」：你现在看到的预览已经全部是系统无衬线字体——标题、描述、数字之外的文字， 跟首页用的是同一套。唯一带字体个性的是签到数字和编号（等宽，用于对齐）。

如果你之后想让工具页「有编辑感一点」，可以只给 wide 行的标题加一行 font-family:"Noto Serif SC",serif（原型文档区的标题就是这个字体，可以对比着看）。 不加 → 完全融入站内；加了 → 工具页有自己的气质。这一步随时可改，不影响其他部分。
