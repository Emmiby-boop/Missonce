去掉卡片网格，让作品和排版说话

上一版给的三个方向（圆角 Bento 网格 / 玻璃拟态 / 霓虹暗色）我自己复看了一遍，都还是 AI 味的三个招牌套路： 统一圆角卡片 + 居中图标 + 统一阴影，是把"模板"当成了"设计"。 这一版换了做法 —— 全部删掉卡片网格，改用细线分隔、衬线中文标题、等宽编号、 全出血的作品图，以及一枚印章当签到按钮。

配色已对齐全站：全部取自现有令牌 —— 主色 #07C160 / #22c55e、 深绿 #006e2f、暗色亮绿 #4ae176；中性色 底 #f7f8fa ↔ #121212、 文字 #1f2a44 ↔ #f3f4f6、次要 #94a3b8 ↔ #9ca3af、 线 #e2e8f0 ↔ #374151。没有引入任何一个新色值。

高级感不是把东西做得更精致，而是删掉更多东西，只留下必须留下的。

删掉了什么

圆角卡片网格、图标色块、玻璃模糊层、霓虹描边、弹性弹跳动效、以及所有自造的新色值

换成了什么

1px 细线分隔的列表、衬线中文标题、等宽字体编号与数字、全出血作品图

为什么高级

卡片是"容器思维"，细线是"版面思维"。容器只能堆，版面能安排层级与视线

记忆点

印章签到：虚线圈 → 盖下变实心绿并回正到 -3°，是"完成一件事"的仪式感

配色纪律

只从现有令牌里取色。主色分两级：#07C160 做装饰线（醒目）、#006e2f 做文字与按钮（保证对比度）

破格元素

横向无限滚动作品带冲出屏幕左右边缘 —— 每屏至少一个元素逃出栅格

小程序落地可行性

  • 配色 100% 复用现有令牌：直接沿用 app.wxss 的 --primary-color / --bg-color / --card-bg / --text-main / --text-sub / --border-color， 以及各页面已在用的 #22c55e / #006e2f / #16a34a / #4ae176。切换 tab 不会出现"另一个产品"的割裂感，也不需要新建设计令牌文件。
  • 主色分两级用：#07C160 只做装饰（主推竖线、编号、进度线），#006e2f 做文字与实心按钮。 这是被可访问性逼出来的分工 —— 亮绿上的白字只有 2.4:1，不合格；深绿才够。现有页面里其实已经混着用了，这里只是把规则明确下来。
  • 单位：原型 390px 宽，小程序 1px ≈ 2rpx。细线务必写 1rpx 而不是 1px，否则高分屏上会变粗、质感全毁。
  • 字体：思源宋体在小程序端可直接用系统宋体兜底 —— iOS 是 Songti SC，Android 可用 Noto Serif CJK。 想更稳就 wx.loadFontFace 加载自托管 woff2 子集。等宽数字必须单独处理：小程序不支持 font-variant-numeric， 要真正等宽就得加载 IBM Plex Mono / JetBrains Mono（只有拉丁数字，20–40KB，很划算）。
  • 作品图：原型里用的是 CSS 渐变占位。落地时 Hero 和作品带要换成真实的头像/壁纸素材（从 resources 集合取精选 8–12 张）， 这是"高级感"真正成立的地方 —— 有作品才有质感，光有排版只是性冷淡。素材整体色调建议控制在绿 / 中性区间，跟全站色板呼应。
  • 印章动画：用 WXSS transition 即可（transform + background），不要用 JS 逐帧。backdrop-filter 只在印章上用一层，性能可控。
  • 作品带横滚：小程序建议用 scroll-view + scroll-x 而不是 CSS 无限动画 —— CSS animation 在后台页面不会自动暂停，会持续耗电。原型里为了演示用了 CSS，落地要换。
  • 后台配置兼容：列表形态下 size: square / wide 失去意义（都渲染成一行）。建议后台改成 key: true 标记主推项， size 字段保留但不再参与渲染 —— 现有配置不会报错，只是视觉统一成列表。
  • D 和 E 其实不是二选一：它们就是同一套设计在暗色模式与浅色模式下的样子。 小程序已开 darkmode: true，建议两个都实现 —— 浅色的 E 跟随系统、暗色的 D 跟随系统， 这才是和全站最一致的做法。

推荐：D + E 都要，按系统深浅色切换。 配色对齐全站之后，"选哪个方向"这个问题其实消失了 —— D 就是现有暗色模式的排法，E 就是现有浅色模式的排法。 你真正要决定的只有一件事：愿不愿意把工具页从"卡片网格"改成"细线列表"。

这个改动的收益是：有了层级（主推项一眼看到）、有了记忆点（印章）、有了内容感（作品带）， 而且不用引入任何新颜色、新字体家族之外的东西。成本是要接一套衬线中文标题 + 一个等宽数字字体， 并把 Hero 和作品带填上真实素材。

如果只想先动一点点，那就只做「布局改列表 + 印章签到」这两件事，字体先保持系统黑体。 去掉卡片网格本身就是"去 AI 味"最有效的一步，占整体效果的七成。
