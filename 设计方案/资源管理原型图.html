资源管理 — 设计规范说明

数据模型（resources 集合）

字段类型说明
titlestring标题（缺省"未命名"）
typeavatar/wallpaper头像/壁纸
coverUrlcloudID封面图 fileID
categoriesstring[]分类数组
tagsstring[]标签数组
statusdraft/review/published/offline草稿/待审/已发布/已下线
aiStatussuccess/pending/failedAI 识别状态
downloadCountnumber下载数
viewCountnumber浏览数
likeCountnumber收藏数
hotScorenumber热度值

功能清单（完整复刻）

分类功能原型位置
单条上传（FAB）① / ②
编辑（点卡片）① → ⑤
删除⑤ 弹窗内
筛选状态 / 类型① 双筛选栏
搜索标题关键词① 导航栏
批量选/AI/改状态/删除⑥ 底部栏
状态正常列表①
空状态②
加载骨架屏③
错误重试④

卡片角标体系

角标取值 / 颜色
状态（左上）已发布绿 / 待审橙 / 已下线灰 / 草稿灰
AI（右上）成功绿✓ / 处理中蓝⏳ / 失败红✗
底部标题 + 下载/浏览量

关键设计决策

决策原因
网格 2 列封面缩略图为主，信息密度适中
双角标状态 + AI 识别需同时可见
删除进弹窗沿用专题/首页Tab交互：卡片无删除
点击卡片编辑与全局交互一致
批量勾选多选 + 底部 AI/状态/删除
状态字符串优先UI 用 draft/review/published/offline

设计规范遵循

规范实现
主色#07C160
封面比例4:5（padding-bottom 125%）
网格2 列，间距 10px
角标毛玻璃 + 语义色
图标Feather 线性 SVG，stroke-width 2
弹窗底部 Sheet，max-height 90%
四态完备loading / empty / error / success
