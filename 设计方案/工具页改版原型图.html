  • 四张卡完全等权重 —— 主推的「头像DIY」和「去水印」长得一样大，用户没有一个明确的"先点哪个"

结构与信息层级（三个方向共用）

区块改动理由
签到卡加入"连续 N/7 天"可视化（火焰 / 圆环 / 霓虹条）给用户每天回来的理由，把一次性动作变成进度
头像 DIY升为跨两列的主推大卡，深色底 + 大图标 + 一句价值主张它是转化主路径，不该和边缘工具等权重
去水印 / 灵感文案降为两张小方卡次级入口，保留可达性但不抢视觉
辣度值改为数值条，等宽字体放大数字 + 「去兑换」数字要像余额一样被看见，不是藏在一张普通卡里
广告位位置不变，样式跟随主题不影响现有变现逻辑

落地到小程序的可行性

  • 单位换算：原型按 390px 宽绘制，小程序 750rpx = 屏宽，1px ≈ 2rpx。例：大圆角 28px → 56rpx。
  • 字体：展示字需要接入。方案① wx.loadFontFace 加载自托管 woff2（ZCOOL KuaiLe 子集约 60–120KB，需按 unicode-range 分片）；方案② 不接字体，改用「系统黑体 + 900 字重 + 字距 -0.02em」，A 方向的圆润感会打折，但层级仍在。
  • 后台配置兼容：现有 toolsConfig 的 size 只有 square / wide。要支持"主推大卡"和"数值条"，建议新增两个值 feature / bar，旧的 square / wide 继续按原逻辑渲染 —— 后台不改也能跑。
  • 深色模式：A / B 都写了深色令牌，小程序端用现有的 @media (prefers-color-scheme: dark) 覆盖即可，组件结构不动。C 只有深色。
  • 性能：backdrop-filter（B 方向玻璃）在低端安卓上会掉帧，建议只对签到 Hero 使用，工具卡改用半透明实色 + 细边框模拟。
  • 广告：插屏 / 原生 / 视频三个广告位的位置与触发逻辑完全不变，只换皮肤。

我推荐 A。理由不是"红色更喜庆"，而是它解决了现在最贵的那个问题 —— 没有品牌人格。 叫「小辣椒」却用通用微信绿，用户记不住你。A 把品牌名变成了视觉资产：辣椒红 + 火焰连签 + 圆润快乐体， 一眼能认出是小辣椒而不是又一个素材站。代价是全局主色要从绿换成红（或至少在工具页 / 我的页局部启用）， 需要和首页、专题页的风格做一次对齐。

如果你担心换主色牵动太多页面，B 是最稳的 —— 沿用绿色系，只重构信息层级和质感， 改动量最小、风险最低，但记忆点也最弱。C 适合做夜间专属皮肤，不适合做默认。
