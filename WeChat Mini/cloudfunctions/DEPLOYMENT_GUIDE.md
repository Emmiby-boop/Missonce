# 🚀 云函数优化版部署指南

## 📋 部署前检查清单

- [ ] 已备份当前云函数（可选但推荐）
- [ ] 微信开发者工具已打开项目
- [ ] 云开发环境已登录
- [ ] `cloud_cache` 集合已创建

---

## 🔧 第一步：创建缓存集合（必需）

在部署云函数之前，需要先创建缓存集合：

### 方法1：通过微信云开发控制台创建

1. 打开 **微信开发者工具**
2. 点击顶部菜单 **云开发**
3. 进入 **数据库** 标签页
4. 点击 **添加集合**
5. 集合名称填写：`cloud_cache`
6. 权限设置选择：**仅创建者可读写**
7. 点击 **确定**

### 方法2：通过云函数创建（备用）

如果控制台创建有问题，可以使用 `updateDatabaseIndexes` 云函数创建。

---

## 📦 第二步：部署优化后的云函数

### 方式一：逐个部署（推荐新手）

#### 1. 部署 getHomeData

1. 在左侧文件目录找到：`cloudfunctions/getHomeData`
2. **右键点击** `getHomeData` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待上传完成（约 1-2 分钟）
5. 在云开发控制台查看云函数是否部署成功

#### 2. 部署 getResources

1. 在左侧文件目录找到：`cloudfunctions/getResources`
2. **右键点击** `getResources` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待上传完成
5. 确认部署成功

#### 3. 部署 getTopics

1. 在左侧文件目录找到：`cloudfunctions/getTopics`
2. **右键点击** `getTopics` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待上传完成
5. 确认部署成功

### 方式二：使用云开发 CLI（高级用户）

如果你安装了 CloudBase CLI：

```bash
# 进入云函数目录
cd WeChat\ Mini/cloudfunctions

# 部署所有云函数
tcb functions:deploy getHomeData
tcb functions:deploy getResources
tcb functions:deploy getTopics
```

## ⚙️ 第三步：验证云函数配置

部署完成后，建议在云开发控制台检查云函数配置：

### 检查 getHomeData

1. 云开发控制台 → 云函数
2. 找到 `getHomeData` → 点击配置
3. 确认配置：
   - 内存：**512MB**
   - 超时时间：**20秒**

### 检查 getResources

1. 找到 `getResources` → 点击配置
2. 确认配置：
   - 内存：**256MB**
   - 超时时间：**15秒**

### 检查 getTopics

1. 找到 `getTopics` → 点击配置
2. 确认配置：
   - 内存：**256MB**
   - 超时时间：**10秒**

## ⚠️ 常见问题

### Q1: 部署时提示依赖安装失败？

**A**: 尝试以下方法：
1. 选择 **"上传并部署：不安装依赖"**
2. 然后在云开发控制台 → 云函数 → 版本 → 安装依赖

### Q2: 缓存功能不工作？

**A**: 检查以下几点：
1. 确认已创建 `cloud_cache` 集合
2. 检查集合权限是否正确（仅创建者可读写）
3. 查看云函数日志是否有缓存相关错误

### Q3: 云函数报错找不到模块？

**A**: 确认：
1. `utils` 文件夹已上传（utils/performance.js 和 utils/cache.js）
2. 云函数目录结构正确

### Q4: 想回退到旧版本？

**A**: 可以通过以下方式回退：
1. 云开发控制台 → 云函数 → 版本管理
2. 找到旧版本 → 点击"设置为当前版本"
3. 或者重新部署旧代码
