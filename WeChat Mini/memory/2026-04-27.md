[2026-04-27 15:17] ## 云存储直连优化（替代 callFunction）

### 方案
用户提出：首次加载走 wx.cloud.callFunction 链路耗时极高（54ms云函数 + 2809ms网络），
改为：prebuildHomepage 每次执行后上传 JSON 到微信云存储，前端直接 wx.request 直连拉取。

### 改动
1. **prebuildHomepage/index.js** — 数据生成后额外上传 JSON 到云存储
   - cloudPath: cloud://miniprogram/home/home_prebuilt_v1.json → miniprogram/home/home_prebuilt_v1.json（自动转CDN）
   - 云数据库 cloud_cache 兜底保留（作为容灾）
   - 返回值新增 cloudStorageUrl 字段
2. **utils/api.js** — _fetchHomeDataFromCloud 重构为三级兜底：
   - ① wx.cloud.getTempFileURL 获取临时链接 → wx.request 直连（主路径）
   - ② wx.cloud.callFunction getHomeData（兜底1）
   - ③ 返回错误（兜底2）
3. **app.js** — preheatCloudFunctions 中直接调用 getHomeData() 而非直接 callFunction
   - 保证预热路径一致走云存储直连
