# 重构分类展示为标签展示

## 核心变更
1. **云函数更新**：修改资源上传逻辑，在保存标签时增加 `type`（头像/壁纸）标识；修改分类获取逻辑，支持直接从标签表读取数据。
2. **小程序端更新**：将头像和壁纸页面的分类导航重构为标签导航，直接展示数据库中的标签内容。

## 技术方案
### 1. 修改云函数 `uploadResource`
- **标签同步逻辑**：在自动同步新标签到 `tags` 集合时，增加 `type: finalType` 字段。
- **查询过滤**：在检查标签是否存在时，增加 `type` 过滤，确保不同类型的标签相互独立。

### 2. 修改云函数 `getCategories`
- **支持标签源**：增加 `source` 参数（可选值：`categories` 或 `tags`）。
- **动态查询**：当 `source='tags'` 时，从 `tags` 集合中读取对应 `type` 的标签作为导航项返回。

### 3. 修改小程序端接口调用 (`utils/api.js`)
- 更新 `getCategories` 封装，支持传递 `source` 参数。

### 4. 修改头像与壁纸页面 (`avatar.js`, `wallpaper.js`)
- **数据获取**：调用 `getCategories` 时传递 `source: 'tags'`。
- **筛选逻辑**：将原来的 `category` 筛选改为 `tag` 筛选，调用 `getResources` 时传递 `tag` 参数。
