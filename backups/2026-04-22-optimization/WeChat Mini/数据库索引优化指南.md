# 微信小程序数据库索引优化建议

## 📋 概述

本文档列出了为提升小程序查询性能建议创建的数据库索引。良好的索引可以将查询速度提升 50-80%。

---

## 🔍 推荐索引列表

### 1. resources 集合（资源表）

#### 复合索引 - 资源列表查询
```javascript
// 用于：按类型+状态+热度查询资源列表
db.collection('resources').createIndex({
  type: 1,
  status: 1,
  hotScore: -1,
  createdAt: -1
})
```

#### 复合索引 - 分类查询
```javascript
// 用于：按类型+状态+分类查询
db.collection('resources').createIndex({
  type: 1,
  status: 1,
  categories: 1
})
```

#### 单字段索引 - 标签查询
```javascript
// 用于：按标签查询
db.collection('resources').createIndex({
  tags: 1
})
```

#### 复合索引 - 日期查询
```javascript
// 用于：按类型+状态+创建时间查询
db.collection('resources').createIndex({
  type: 1,
  status: 1,
  createdAt: -1
})
```

#### 单字段索引 - 每日热度
```javascript
// 用于：按每日热度排序
db.collection('resources').createIndex({
  dailyHotScore: -1
})
```

## 📊 索引创建方式

### 方式一：通过云开发控制台创建

1. 登录 [微信云开发控制台](https://cloud.weixin.qq.com/)
2. 选择你的云开发环境
3. 进入「数据库」页面
4. 选择对应的集合
5. 点击「索引」标签
6. 点击「添加索引」
7. 按照上述配置填写索引字段和排序方式
8. 点击「确定」创建

### 方式二：通过云函数批量创建

创建一个云函数来批量创建所有索引：

```javascript
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

const indexesConfig = [
  {
    collection: 'resources',
    indexes: [
      { name: 'type_status_hotScore_createdAt', keys: { type: 1, status: 1, hotScore: -1, createdAt: -1 } },
      { name: 'type_status_categories', keys: { type: 1, status: 1, categories: 1 } },
      { name: 'tags', keys: { tags: 1 } },
      { name: 'type_status_createdAt', keys: { type: 1, status: 1, createdAt: -1 } },
      { name: 'dailyHotScore', keys: { dailyHotScore: -1 } }
    ]
  },
  {
    collection: 'favorites',
    indexes: [
      { name: 'openid_createTime', keys: { _openid: 1, createTime: -1 } },
      { name: 'openid_resourceId', keys: { _openid: 1, resourceId: 1 } },
      { name: 'openid_type_createTime', keys: { _openid: 1, type: 1, createTime: -1 } }
    ]
  },
  {
    collection: 'likes',
    indexes: [
      { name: 'openid_createTime', keys: { _openid: 1, createTime: -1 } },
      { name: 'openid_resourceId', keys: { _openid: 1, resourceId: 1 } }
    ]
  },
  {
    collection: 'downloads',
    indexes: [
      { name: 'openid_createTime', keys: { _openid: 1, createTime: -1 } },
      { name: 'openid_type_createTime', keys: { _openid: 1, type: 1, createTime: -1 } }
    ]
  },
  {
    collection: 'browse_history',
    indexes: [
      { name: 'openid_createTime', keys: { _openid: 1, createTime: -1 } },
      { name: 'openid_type_createTime', keys: { _openid: 1, type: 1, createTime: -1 } }
    ]
  },
  {
    collection: 'banners',
    indexes: [
      { name: 'status_sort', keys: { status: 1, sort: 1 } }
    ]
  },
  {
    collection: 'categories',
    indexes: [
      { name: 'enabled', keys: { enabled: 1 } },
      { name: 'type_enabled', keys: { type: 1, enabled: 1 } }
    ]
  },
  {
    collection: 'home_sections',
    indexes: [
      { name: 'enable_sort', keys: { enable: 1, sort: 1 } }
    ]
  }
]

exports.main = async (event) => {
  const results = []
  
  for (const { collection, indexes } of indexesConfig) {
    const collectionResult = { collection, success: [], failed: [] }
    
    for (const index of indexes) {
      try {
        await cloud.database().createCollectionIndex({
          collectionName: collection,
          indexName: index.name,
          indexKeys: index.keys
        })
        collectionResult.success.push(index.name)
      } catch (error) {
        collectionResult.failed.push({ name: index.name, error: error.message })
      }
    }
    
    results.push(collectionResult)
  }
  
  return {
    success: true,
    results
  }
}
```

## ⚠️ 注意事项

### 1. 索引的利弊

**优点：**
- 大幅提升查询速度
- 减少数据库扫描次数
- 降低云函数执行时间

**缺点：**
- 增加存储空间占用（约增加 10-30%）
- 写入操作（增删改）会变慢
- 需要维护索引

### 2. 索引创建时机

- ✅ **推荐**：在业务低峰期创建索引
- ❌ **避免**：在用户访问高峰期创建索引
- ⚠️ **注意**：大集合创建索引可能需要较长时间

### 3. 索引监控

创建索引后，建议监控：
- 查询性能是否提升
- 写入性能是否受影响
- 存储空间增长情况

### 4. 索引删除

如果发现某个索引没有用到，可以安全删除：

```javascript
// 通过云开发控制台删除
// 或通过云函数删除
cloud.database().dropCollectionIndex({
  collectionName: 'resources',
  indexName: 'index_name'
})
```
