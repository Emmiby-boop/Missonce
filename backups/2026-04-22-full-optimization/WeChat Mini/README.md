# QClaw 小程序

微信小程序项目，使用微信云开发服务。

## 项目结构

```
├── pages/              # 主包页面
│   ├── index/          # 首页
│   ├── avatar/         # 头像页
│   ├── wallpaper/      # 壁纸页
│   └── profile/        # 个人中心
├── subpackages/        # 分包页面
│   ├── daily-picks/    # 每日推荐
│   ├── preview/        # 头像预览
│   ├── wallpaper-preview/  # 壁纸预览
│   ├── inspiration-writer/ # 灵感文案
│   ├── favorites/      # 收藏
│   └── ...
├── cloudfunctions/     # 云函数
├── components/         # 自定义组件
├── utils/              # 工具函数
├── config/             # 配置文件
└── images/             # 静态图片
```

## 主要功能

- **首页** - 轮播图、快捷功能入口、专区推荐
- **壁纸/头像** - 分类浏览、标签筛选、瀑布流展示
- **每日推荐** - 每日精选壁纸头像
- **灵感文案** - 精选文案库，一键复制
- **个人中心** - 收藏、下载、积分、设置

## 技术栈

- 前端：微信小程序原生开发
- 后端：微信云开发（云函数 + 云数据库 + 云存储）
- 缓存：本地 Storage + 后台静默刷新机制

## 开发指南

### 环境要求

- 微信开发者工具
- Node.js 16+

### 启动项目

1. 用微信开发者工具打开项目目录
2. 配置 `project.config.json` 中的 AppID
3. 部署云函数到云端

### 主要云函数

| 云函数 | 功能 |
|--------|------|
| `getResources` | 获取资源列表 |
| `getDailyPicks` | 获取每日推荐 |
| `getQuotes` | 获取文案列表 |
| `getHomeData` | 获取首页数据 |
| `toggleInteraction` | 点赞/收藏操作 |

## 缓存策略

| 数据类型 | 缓存时间 | 静默刷新 |
|----------|----------|----------|
| 资源列表 | 15分钟 | ✓ |
| 分类标签 | 30分钟 | - |
| 首页数据 | 15分钟 | ✓ |
| 每日推荐 | 24小时 | - |
| 文案列表 | 15分钟 | ✓ |
