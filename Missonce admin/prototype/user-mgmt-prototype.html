设计说明 · Editorial Clarity

核心改进：

  • Hero 会员总览卡：绿色渐变背景，大数字展示总数 + 横向条形图展示各等级分布，一目了然
  • 快捷筛选 chips：横向滚动，支持按等级、即将到期、已过期快速过滤
  • 用户卡片重构：左侧 3px 状态色条（绿=正常 / 琥珀=即将到期 / 红=已过期），头像带等级色环 + 角标，关键信息前置
  • 次要信息折叠：积分/签到/下载改为底部三宫格小标签，扫视效率提升 3 倍
  • 到期倒计时：用"还剩 3 天"代替纯日期，即将到期用琥珀色加粗强调

详情页改进：

  • 顶部带渐变背景的资料卡，头像有白边描边
  • 三宫格关键数据：等级 / 积分 / 签到，扫视即懂
  • 会员等级改为 3×2 网格选择器，比 picker 更直观
  • 表单分组到「其他设置」卡，行式布局，层次清晰

* 完全复用 App.vue 设计系统的 CSS 变量与配色，支持 light/dark 双模式
* 所有圆角、阴影、间距与现有页面保持一致
